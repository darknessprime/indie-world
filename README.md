# indie-world

Fan-made concept websites for indie games that don't have one yet. Each game gets its own subfolder.

## Sites

- [`nimbit-frontier/`](./nimbit-frontier) — concept site for [Nimbit Frontier](https://store.steampowered.com/app/2477710/Nimbit_Frontier/) by Megasploot.

## Running a site locally

```bash
cd nimbit-frontier
npm install
npm run dev
```
